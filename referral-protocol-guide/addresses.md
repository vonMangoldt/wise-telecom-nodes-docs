# Contract Addresses

The contracts of the vault mesh and the referral system, per chain.

Every address here is copied from a configuration record in the vault repository, [wise-telecom-nodes-v2](https://github.com/wise-foundation/wise-telecom-nodes-v2), never typed by hand, and the record is the source of truth. The vault diamonds are deployed with CREATE3, so a product has the same address on every chain it runs on, and every USD token in the mesh has six decimals. The four registries, the hub and the reader are deployed and their source is verified on each chain's explorer (Etherscan on mainnet, Basescan on Base, Arbiscan on Arbitrum, Blockscout through Sourcify on Robinhood Chain); their rows are read from the records the deploy scripts wrote. The vault facets of the registry round are deployed on every chain and their selector routes are queued on all nine vaults behind the three day timelock; the facet rows below are filled from the upgrade scripts' broadcast records once the routes execute, and the flush round follows the same way.

> Before you use an address, read it from its configuration file and check it onchain with `cast code <address> --rpc-url <rpc>`, which must return bytecode.
